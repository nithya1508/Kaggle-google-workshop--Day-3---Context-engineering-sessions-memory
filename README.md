**Vertex AI Agents – Hands-On Lab Series (Day 1–3)**

This repository contains my complete hands-on learning journey with Google Cloud Vertex AI Agents, built through a structured set of labs across three days. The series covers the foundations of agentic systems, production-ready architectures, tool integrations, session management, and different types of memory that enable context-aware AI interactions.

These notebooks collectively demonstrate how to build agents that can reason, act, use tools, remember past context, and maintain long-running multi-step conversations—core capabilities required to develop real-world AI applications.

**📁 Repository Structure
Day 1 – Agent Fundamentals**

**day-1a-from-prompt-to-action.ipynb**
Introduction to agent prompting, environment setup, project configuration, and how Vertex AI Agents translate natural language into structured actions.

**day-1b-agent-architectures.ipynb**
Deep dive into agent architectures: remote vs. local agents, deployment workflows, streaming responses, asynchronous querying, and interaction patterns.

**Day 2 – Agent Tools & Best Practices**

**day-2a-agent-tools.ipynb**
Overview of the tool ecosystem within Vertex AI Agents. Demonstrates how agents use tools such as search, retrieval, calculators, APIs, and custom-defined functions to extend their capabilities beyond pure text generation.

**day-2b-agent-tools-best-practices.ipynb**
A practical guide to designing production-grade tools for agents. Covers error handling, validation flows, safe execution patterns, multi-tool orchestration, and structural best practices for reliable tool-enabled AI systems.

**Day 3 – Sessions & Memory**

**day-3a-agent-sessions.ipynb**
Explains how agents manage sessions, maintain conversation continuity, and handle multi-turn dialogues. Covers session creation, state persistence, user identity, and designing workflows where context evolves over time.

**day-3b-agent-memory.ipynb**
Focuses on different types of memory used by agents, including short-term, long-term, user-specific, and system memory. Demonstrates how memory allows an agent to recall previous interactions, personalize responses, and handle complex multi-step tasks.
